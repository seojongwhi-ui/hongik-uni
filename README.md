# 자동차 논문 프로젝트

이 폴더는 자동차 관련 논문을 준비하기 위한 작업 공간입니다.

## 기본 흐름

1. `outline.md`에서 논문 주제와 목차를 잡습니다.
2. `notes.md`에 읽은 자료, 아이디어, 실험 메모를 모읍니다.
3. `references.bib`에 참고문헌 정보를 정리합니다.
4. `survey_questions.tsv`에서 설문 문항을 관리합니다.
5. `create_google_form.gs`로 구글폼과 응답 구글시트를 생성합니다.

## 다음에 정할 것

- 논문 주제
- 연구 질문
- 사용할 데이터 또는 분석 방법
- 제출 형식

## 설문 파일

- `survey_questions.tsv`: 설문 문항표
- `survey_response_template.tsv`: 구글시트 응답 헤더 템플릿
- `create_google_form.gs`: 구글폼 자동 생성 스크립트
- `google_form_사용법.md`: 구글폼 생성 절차
- `research_participation_notice.md`: 연구 참여 안내 및 동의 문구
